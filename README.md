# YUJIMIN iPhone — Ultimate Fan-made Edition

실제 인물의 기기나 개인정보를 복제한 것이 아닌 팬메이드 가상 아이폰 UI입니다.

## 암호
`000411`

## 포함 기능
- 잠금화면
- Face ID 데모
- 6자리 암호 입력
- Dynamic Island 데모
- 홈화면 + 위젯
- Spotlight 검색
- Control Center
- Notification Center
- App Switcher
- 카카오톡 데모 채팅
- 메시지
- 전화 키패드
- 사진 + 사진 확대
- 카메라
- Safari
- 메모
- 음악
- 캘린더
- 시계
- 날씨
- 설정
- 배터리 API 지원 브라우저에서 배터리 표시
- PWA 설치 지원
- 오프라인 캐시(Service Worker)

## GitHub Pages 업로드
저장소에 다음 파일을 그대로 업로드:
- index.html
- style.css
- script.js
- manifest.json
- sw.js
- README.md

그 다음 Settings → Pages → Deploy from a branch → main → /(root) → Save.
